# docs/

Plans for work we've decided on but not executed yet. Each file is a self-contained
implementation plan: detailed enough that anyone (a developer or an AI) can pick it up
cold and build it without needing the conversation that produced it.

Convention: `NN-short-name.md`, numbered in the order they were written, not the order
they'll be built. Each plan states its own priority/status at the top.
